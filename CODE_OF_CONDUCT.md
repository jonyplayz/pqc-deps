# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, focus on the
evidence rather than the person, and don't harass anyone. Library maintainers
who disagree with how their project is described are especially welcome to
correct us: please point to a source and we'll fix it.

## Reporting

Report unacceptable behaviour privately to the maintainers through a
[private security advisory](https://github.com/jonyplayz/pqc-deps/security/advisories/new)
(it reaches only the maintainers). Reports are handled confidentially.
Maintainers may edit or remove contributions and block participants who break
this code.
